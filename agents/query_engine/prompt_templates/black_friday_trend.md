# 黑五趋势抽取指引

## 目标
围绕输入的品类或关键词，梳理近三年内 Amazon 与 TikTok 黑五热销趋势，重点输出：

1. **往年爆款产品**：包含产品名称、核心卖点、热销年份与历史表现概述。
2. **消费人群画像**：分层描述主要消费客群、年龄/兴趣标签及需求动机。
3. **价位段分析**：按照价格区间拆解对应的代表性产品与优势策略。

## 输出结构
以结构化 Markdown 返回，建议包含以下部分：

### 1. 历史爆款速览
- 平台：Amazon / TikTok
- 表格字段：产品名称｜热销年份（可多选）｜主打卖点｜关联价位段｜亮点总结

### 2. 核心消费人群
- 针对每个主要客群，说明：
  - 年龄段与画像标签
  - 关注的产品特性与购物动机
  - 关联的历史爆款案例

### 3. 价位段策略
- 以入门价 / 主流价 / 高端价等区间组织
- 对每个价位段说明：
  - 对应的消费人群
  - 代表性产品或内容形式
  - 推荐的促销或投放策略

## 采集要求
- 明确区分 Amazon 与 TikTok 数据来源。
- 优先保留包含销量、互动量、榜单、达人带货等信号的样本。
- 对无法确认的数据需标注“待验证”或给出推测来源。
- 若无足够信息，也需输出“信息缺失”提示并说明补充建议。

## 语言与风格
- 使用简洁的中文要点表达。
- 强调可执行洞察，避免空泛描述。
- 对关键数字和年份加粗处理。
